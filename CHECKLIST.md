## Проверки

Команды запуска и проверки:

```powershell
pip install -r requirements.txt
python main.py
python -m pytest -q
python -m flake8
```

Фактические результаты интеграционной проверки текущей версии:

- `python -m pytest -q` с `pytest==8.3.3` - `152 passed`;
- `python -m flake8` с `flake8==7.1.1` - успешно, без замечаний.

При демонстрации в терминале нужно добавить место, поездку и посещение,
завершить работу и повторно запустить приложение с тем же каталогом данных.
Этот сценарий показывает сохранение пользовательских изменений в SQLite;
инструкция не является отметкой о выполнении ручной демонстрации.

Если рабочая папка станет Git-репозиторием, отдельно можно проверить:

```powershell
git status
git log --oneline
```

Эти Git-команды не являются обязательным подтверждением для текущей папки,
потому что сейчас ее статус как репозитория не подтвержден.
